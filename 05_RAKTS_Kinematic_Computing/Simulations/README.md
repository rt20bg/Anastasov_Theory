# Kinematic Computer Simulations (RAKTS)

This directory contains Python scripts and generated data demonstrating the concept of Continuous-Variable Kinematic Computing using analog fluid dynamics.

## Prerequisites & How to Run

To run these simulations, you will need Python installed along with the required mathematical and scientific libraries.

1. **Install Dependencies:**
   Open your terminal and install the required packages:
   ```bash
   pip install numpy matplotlib scipy joblib
   ```

2. **Execute the Scripts:**
   Navigate to this directory in your terminal and run the scripts via Python:
   
   *For the basic physics simulation:*
   ```bash
   python rakts_logic_gate.py
   ```
   
   *For the optimized logic composer:*
   ```bash
   python "FASTER optimized_rakts_kinematic_logic.py"
   ```
   
   *For the parallel multi-core stress test:*
   ```bash
   python parallel_rakts_kinematic_logic.py
   ```

## Code Files

1. **`rakts_logic_gate.py`**
   - **Purpose:** The core, initial proof-of-concept simulation.
   - **What it does:** Solves the full Ordinary Differential Equations (ODEs) for a Universal Kinematic NAND gate. It demonstrates the physical principle where a Background Bias field acts as an inverter.
   - **When to use:** Use this to study the underlying physics and mathematics of the framework.

2. **`FASTER optimized_rakts_kinematic_logic.py`**
   - **Purpose:** Optimized logic composer.
   - **What it does:** Instead of solving the expensive ODE for every single gate in a circuit, it precomputes the 4 basic states of the physical NAND gate just once. It then uses pure logic to rapidly compose complex circuits such as NOT, AND, OR, NOR, XOR, and Half-Adders.
   - **When to use:** Use this for fast testing and for building complex logical circuits.

3. **`parallel_rakts_kinematic_logic.py`**
   - **Purpose:** High-performance simulator (Parallel Processing).
   - **What it does:** Identical in logic to the optimized script, but utilizes `joblib` to distribute heavy workloads (like noise robustness tests and parameter sweeps) across all CPU cores (optimized for an i5-12400F with 6 cores / 12 threads).
   - **When to use:** Use this to generate large datasets and run heavy statistical stress tests.

## Results (Plots and Data)
The scripts automatically generate and save their outputs in this directory:
- `kinematic_nand_output.png` / `kinematic_gate_output.png`: Vector state plots from the basic simulator.
- `parallel_rakts_overview.png`: Summary infographic from the parallel stress tests.
- `parallel_rakts_results.csv`: Raw data generated by the robustness and parameter sweep tests.
